# Governance

## Project origin

OptiQuake Local was initiated by **Lic. Juan Esteban Ramírez** from a locally validated experiment using webcam video as an optical vibration signal.

## Open collaboration

The project is AGPL-3.0-licensed. Anyone may fork it, study it, improve it, redistribute it, or build compatible implementations subject to the license.

## Maintainer model

- The original author remains credited as project creator.
- Contributors retain attribution for their accepted work through Git history and release notes.
- Pull requests should be evaluated on reproducibility, safety, code quality, interoperability, and evidence.
- Architecture should remain vendor-neutral wherever practical.
- No contributor should need access to JARVIS, OpenClaw, PC2-ULTRA-PRO, or other private systems to develop the public core.

## Scientific claims

Experimental observations, vibration detection, seismic-event classification, and earthquake early warning are different claims. Documentation and releases must state which level has actually been validated.

## Compatibility

Public interfaces should favor stable JSON events and documented adapters so independent AI systems can integrate without modifying the detector core.
