# OptiQuake Local — Public project records and discovery

OptiQuake Local is an **experimental local optical vibration monitoring/detection platform** using camera-derived scene motion. It is **not** a certified earthquake detector, validated seismic classifier, earthquake prediction tool, or guaranteed early-warning system.

Consult the [README](README.md) for prerequisites, installation instructions, self-test and supported hardware. Package installation is documented on [PyPI](https://pypi.org/project/optiquake-local/). Do not use this software for life-safety decisions or as a substitute for official emergency warnings.

## Metrics interpretation

PyPI download counts are package-download events, **not verified unique users or installations**. GitHub views/clones may require repository traffic permissions and can be unavailable; missing values are not zero. Zenodo record views and file downloads are distinct metrics.
