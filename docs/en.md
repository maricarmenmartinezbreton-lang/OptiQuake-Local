# OptiQuake Local — English
**Creator:** Lic. Juan Esteban Ramírez — Dominican Republic.

OptiQuake Local is an open-source experimental platform that uses compatible webcams as auxiliary optical vibration sensors.

## Install
`python -m pip install optiquake-local`

## Integrations
- AI-system skill interface.
- Plugin API v1 for community extensions.
- JSONL event stream for automation.
- Architecture prepared for multi-sensor correlation.

## Scientific limits
The current release demonstrates local vibration observability. It is not a certified seismometer, does not predict earthquakes, does not estimate magnitude, and is not by itself a guaranteed earthquake early-warning system.
