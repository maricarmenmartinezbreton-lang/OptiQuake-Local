# OptiQuake Local — Bahasa Indonesia
**Pembuat:** Lic. Juan Esteban Ramírez — Republik Dominika.

OptiQuake Local adalah platform eksperimental sumber terbuka yang menggunakan webcam kompatibel sebagai sensor getaran optik tambahan.

## Instalasi
`python -m pip install optiquake-local`

## Integrasi
- Antarmuka skill untuk sistem AI.
- Plugin API v1 untuk ekstensi komunitas.
- Aliran peristiwa JSONL untuk otomatisasi.
- Arsitektur siap untuk korelasi multisensor.

## Batas ilmiah
Versi saat ini menunjukkan bahwa getaran lokal dapat diamati. Ini bukan seismometer tersertifikasi, tidak memprediksi gempa, tidak memperkirakan magnitudo, dan bukan sistem peringatan dini gempa yang dijamin jika digunakan sendiri.
