# OptiQuake Local — Deutsch
**Urheber:** Lic. Juan Esteban Ramírez — Dominikanische Republik.

OptiQuake Local ist eine experimentelle Open-Source-Plattform, die kompatible Webcams als zusätzliche optische Vibrationssensoren nutzt.

## Installation
`python -m pip install optiquake-local`

## Integrationen
- Skill-Schnittstelle für KI-Systeme.
- Plugin API v1 für Community-Erweiterungen.
- JSONL-Ereignisstrom für Automatisierung.
- Architektur für Multisensor-Korrelation vorbereitet.

## Wissenschaftliche Grenzen
Die aktuelle Version weist die lokale Beobachtbarkeit von Vibrationen nach. Sie ist kein zertifiziertes Seismometer, sagt keine Erdbeben voraus, schätzt keine Magnitude und ist allein kein garantiertes Erdbeben-Frühwarnsystem.
