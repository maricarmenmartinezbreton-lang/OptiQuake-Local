# OptiQuake Local — Deutsch

**Ersteller:** Lic. Juan Esteban Ramírez — Dominikanische Republik.

OptiQuake Local ist eine experimentelle Open-Source-Plattform, die kompatible Webcams als optische Hilfssensoren für Vibrationen verwendet.

## Installation
`python -m pip install optiquake-local`

## Integrationen
- Skill für KI-Systeme.
- Plugin API v1 für Community-Erweiterungen.
- JSONL-Ereignisstrom für Automatisierung.
- Architektur für Multi-Sensor-Korrelation vorbereitet.

## Wissenschaftliche Grenzen
Die aktuelle Version weist lokale Vibrationsbeobachtbarkeit nach. Sie ist kein zertifiziertes Seismometer, sagt keine Erdbeben voraus, schätzt keine Magnitude und ist allein kein garantiertes Frühwarnsystem.
