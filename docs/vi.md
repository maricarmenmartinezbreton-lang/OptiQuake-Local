# OptiQuake Local — Tiếng Việt
**Tác giả:** Lic. Juan Esteban Ramírez — Cộng hòa Dominica.

OptiQuake Local là nền tảng thử nghiệm mã nguồn mở sử dụng webcam tương thích như cảm biến quang học phụ trợ để quan sát rung động.

## Cài đặt
`python -m pip install optiquake-local`

## Tích hợp
- Giao diện skill cho hệ thống AI.
- Plugin API v1 cho phần mở rộng cộng đồng.
- Luồng sự kiện JSONL cho tự động hóa.
- Kiến trúc sẵn sàng cho tương quan đa cảm biến.

## Giới hạn khoa học
Phiên bản hiện tại chứng minh khả năng quan sát rung động cục bộ. Đây không phải là địa chấn kế được chứng nhận, không dự đoán động đất, không ước tính độ lớn và không tự thân là hệ thống cảnh báo sớm động đất được bảo đảm.
