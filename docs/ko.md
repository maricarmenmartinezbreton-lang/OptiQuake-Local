# OptiQuake Local — 한국어
**개발자:** Lic. Juan Esteban Ramírez — 도미니카 공화국.

OptiQuake Local은 호환 웹캠을 보조 광학 진동 센서로 사용하는 오픈소스 실험 플랫폼입니다.

## 설치
`python -m pip install optiquake-local`

## 통합
- AI 시스템용 스킬 인터페이스.
- 커뮤니티 확장을 위한 Plugin API v1.
- 자동화를 위한 JSONL 이벤트 스트림.
- 다중 센서 상관 분석을 위한 확장 가능한 구조.

## 과학적 한계
현재 버전은 로컬 진동의 관측 가능성을 입증합니다. 인증된 지진계가 아니며 지진을 예측하거나 규모를 추정하지 않고, 그 자체만으로 보장된 지진 조기경보 시스템이 아닙니다.
