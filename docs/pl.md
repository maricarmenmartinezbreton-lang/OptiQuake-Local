# OptiQuake Local — Polski
**Twórca:** Lic. Juan Esteban Ramírez — Republika Dominikańska.

OptiQuake Local to eksperymentalna platforma open source wykorzystująca kompatybilne kamery internetowe jako pomocnicze optyczne czujniki drgań.

## Instalacja
`python -m pip install optiquake-local`

## Integracje
- Interfejs skill dla systemów AI.
- Plugin API v1 dla rozszerzeń społeczności.
- Strumień zdarzeń JSONL do automatyzacji.
- Architektura przygotowana do korelacji wieloczujnikowej.

## Ograniczenia naukowe
Obecna wersja pokazuje możliwość lokalnej obserwacji drgań. Nie jest certyfikowanym sejsmometrem, nie przewiduje trzęsień ziemi, nie szacuje magnitudy i sama w sobie nie jest gwarantowanym systemem wczesnego ostrzegania.
