# OptiQuake Local — עברית
**יוצר:** Lic. Juan Esteban Ramírez — הרפובליקה הדומיניקנית.

OptiQuake Local היא פלטפורמת קוד פתוח ניסיונית המשתמשת במצלמות רשת תואמות כחיישני רעידות אופטיים מסייעים.

## התקנה
`python -m pip install optiquake-local`

## אינטגרציות
- ממשק Skill למערכות AI.
- Plugin API v1 להרחבות קהילתיות.
- זרם אירועי JSONL לאוטומציה.
- ארכיטקטורה המוכנה לקורלציה בין מספר חיישנים.

## מגבלות מדעיות
הגרסה הנוכחית מדגימה שניתן לצפות ברעידות מקומיות. היא אינה סייסמומטר מוסמך, אינה מנבאת רעידות אדמה, אינה מעריכה מגניטודה ואינה מהווה לבדה מערכת מובטחת להתרעה מוקדמת מפני רעידות אדמה.
