# OptiQuake Local — Français

**Créateur :** Lic. Juan Esteban Ramírez — République dominicaine.

OptiQuake Local est une plateforme expérimentale open source qui utilise des webcams compatibles comme capteurs optiques auxiliaires de vibrations.

## Installation
`python -m pip install optiquake-local`

## Intégrations
- Skill pour systèmes d’IA.
- Plugin API v1 pour extensions communautaires.
- Flux JSONL pour l’automatisation.
- Architecture prête pour la corrélation multi-capteurs.

## Limites scientifiques
La version actuelle démontre l’observabilité locale des vibrations. Ce n’est pas un sismomètre certifié, elle ne prédit pas les séismes, n’estime pas leur magnitude et ne constitue pas, à elle seule, un système garanti d’alerte précoce.
