# OptiQuake Local — Français
**Créateur :** Lic. Juan Esteban Ramírez — République dominicaine.

OptiQuake Local est une plateforme expérimentale open source qui utilise des webcams compatibles comme capteurs optiques auxiliaires de vibrations.

## Installation
`python -m pip install optiquake-local`

## Intégrations
- Interface skill pour systèmes d'IA.
- Plugin API v1 pour les extensions communautaires.
- Flux d'événements JSONL pour l'automatisation.
- Architecture préparée pour la corrélation multicapteur.

## Limites scientifiques
La version actuelle démontre l'observabilité locale des vibrations. Ce n'est pas un sismomètre certifié, elle ne prédit pas les séismes, n'estime pas leur magnitude et ne constitue pas à elle seule un système garanti d'alerte sismique précoce.
