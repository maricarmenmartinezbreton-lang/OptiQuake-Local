# OptiQuake Local — Bahasa Melayu
**Pencipta:** Lic. Juan Esteban Ramírez — Republik Dominika.

OptiQuake Local ialah platform eksperimen sumber terbuka yang menggunakan kamera web serasi sebagai penderia getaran optik tambahan.

## Pemasangan
`python -m pip install optiquake-local`

## Integrasi
- Antara muka skill untuk sistem AI.
- Plugin API v1 untuk sambungan komuniti.
- Aliran peristiwa JSONL untuk automasi.
- Seni bina yang disediakan untuk korelasi berbilang penderia.

## Had saintifik
Versi semasa menunjukkan bahawa getaran setempat boleh diperhatikan. Ia bukan seismometer yang diperakui, tidak meramal gempa bumi, tidak menganggarkan magnitud dan bukan, dengan sendirinya, sistem amaran awal gempa bumi yang dijamin.
