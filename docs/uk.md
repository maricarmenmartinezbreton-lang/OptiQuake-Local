# OptiQuake Local — Українська
**Автор:** Lic. Juan Esteban Ramírez — Домініканська Республіка.

OptiQuake Local — експериментальна платформа з відкритим кодом, що використовує сумісні вебкамери як допоміжні оптичні датчики вібрації.

## Встановлення
`python -m pip install optiquake-local`

## Інтеграції
- Skill-інтерфейс для систем ШІ.
- Plugin API v1 для розширень спільноти.
- Потік подій JSONL для автоматизації.
- Архітектура, готова до багатосенсорної кореляції.

## Наукові обмеження
Поточна версія демонструє локальну спостережуваність вібрацій. Це не сертифікований сейсмометр; система не прогнозує землетруси, не оцінює магнітуду і сама по собі не є гарантованою системою раннього попередження.
