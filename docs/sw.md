# OptiQuake Local — Kiswahili
**Muundaji:** Lic. Juan Esteban Ramírez — Jamhuri ya Dominika.

OptiQuake Local ni jukwaa la majaribio la chanzo huria linalotumia kamera za wavuti zinazooana kama vihisi vya ziada vya mtetemo wa macho.

## Usakinishaji
`python -m pip install optiquake-local`

## Miunganisho
- Kiolesura cha skill kwa mifumo ya AI.
- Plugin API v1 kwa viendelezi vya jamii.
- Mtiririko wa matukio wa JSONL kwa uotomatiki.
- Muundo ulio tayari kwa uhusianishaji wa vihisi vingi.

## Mipaka ya kisayansi
Toleo la sasa linaonyesha kwamba mitetemo ya eneo inaweza kuonekana. Si seismometer iliyoidhinishwa, haitabiri matetemeko ya ardhi, haikadirii magnitude, na yenyewe si mfumo wa tahadhari ya mapema wa tetemeko la ardhi uliothibitishwa.
