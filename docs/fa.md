# OptiQuake Local — فارسی
**سازنده:** Lic. Juan Esteban Ramírez — جمهوری دومینیکن.

OptiQuake Local یک پلتفرم آزمایشی متن‌باز است که از وب‌کم‌های سازگار به‌عنوان حسگرهای نوری کمکی برای مشاهده لرزش استفاده می‌کند.

## نصب
`python -m pip install optiquake-local`

## یکپارچه‌سازی
- رابط Skill برای سامانه‌های هوش مصنوعی.
- Plugin API v1 برای افزونه‌های جامعه.
- جریان رویداد JSONL برای خودکارسازی.
- معماری آماده برای همبستگی چندحسگری.

## محدودیت‌های علمی
نسخه فعلی قابلیت مشاهده محلی لرزش را نشان می‌دهد. این سامانه لرزه‌نگار تأییدشده نیست، زلزله را پیش‌بینی نمی‌کند، بزرگی را برآورد نمی‌کند و به‌تنهایی سامانه تضمین‌شده هشدار سریع زلزله محسوب نمی‌شود.
