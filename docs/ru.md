# OptiQuake Local — Русский

**Автор:** Lic. Juan Esteban Ramírez — Доминиканская Республика.

OptiQuake Local — экспериментальная платформа с открытым исходным кодом, использующая совместимые веб-камеры как вспомогательные оптические датчики вибрации.

## Установка
`python -m pip install optiquake-local`

## Интеграции
- Skill для систем ИИ.
- Plugin API v1 для расширений сообщества.
- Поток событий JSONL для автоматизации.
- Архитектура, подготовленная для корреляции нескольких датчиков.

## Научные ограничения
Текущая версия демонстрирует возможность локального наблюдения вибраций. Это не сертифицированный сейсмометр, она не предсказывает землетрясения, не оценивает магнитуду и сама по себе не является гарантированной системой раннего предупреждения.
