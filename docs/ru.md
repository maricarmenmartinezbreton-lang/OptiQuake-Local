# OptiQuake Local — Русский
**Создатель:** Lic. Juan Esteban Ramírez — Доминиканская Республика.

OptiQuake Local — экспериментальная платформа с открытым исходным кодом, использующая совместимые веб-камеры как вспомогательные оптические датчики вибрации.

## Установка
`python -m pip install optiquake-local`

## Интеграции
- Skill-интерфейс для систем ИИ.
- Plugin API v1 для расширений сообщества.
- Поток событий JSONL для автоматизации.
- Архитектура, подготовленная для многосенсорной корреляции.

## Научные ограничения
Текущая версия демонстрирует локальную наблюдаемость вибраций. Это не сертифицированный сейсмометр; система не предсказывает землетрясения, не оценивает магнитуду и сама по себе не является гарантированной системой раннего предупреждения о землетрясениях.
