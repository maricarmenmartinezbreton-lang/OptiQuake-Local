# OptiQuake Local — العربية

**المُنشئ:** Lic. Juan Esteban Ramírez — جمهورية الدومينيكان.

OptiQuake Local منصة تجريبية مفتوحة المصدر تستخدم كاميرات ويب متوافقة كمستشعرات بصرية مساعدة للاهتزاز.

## التثبيت
`python -m pip install optiquake-local`

## التكاملات
- Skill لأنظمة الذكاء الاصطناعي.
- Plugin API v1 لإضافات المجتمع.
- تدفق أحداث JSONL للأتمتة.
- بنية مهيأة لربط بيانات عدة مستشعرات.

## الحدود العلمية
الإصدار الحالي يثبت إمكانية رصد الاهتزازات محليًا. وهو ليس مقياس زلازل معتمدًا، ولا يتنبأ بالزلازل، ولا يقدّر شدتها، ولا يشكل بمفرده نظام إنذار مبكر مضمونًا.
