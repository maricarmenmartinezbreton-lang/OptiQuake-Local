# OptiQuake Local — العربية
**المطوّر:** Lic. Juan Esteban Ramírez — جمهورية الدومينيكان.

OptiQuake Local منصة تجريبية مفتوحة المصدر تستخدم كاميرات الويب المتوافقة كمستشعرات بصرية مساعدة للاهتزاز.

## التثبيت
`python -m pip install optiquake-local`

## التكاملات
- واجهة Skill لأنظمة الذكاء الاصطناعي.
- Plugin API v1 لإضافات المجتمع.
- تدفق أحداث JSONL للأتمتة.
- بنية مهيأة للربط بين عدة مستشعرات.

## الحدود العلمية
يثبت الإصدار الحالي إمكانية رصد الاهتزازات محليًا. وهو ليس مقياس زلازل معتمدًا، ولا يتنبأ بالزلازل أو يقدّر قوتها، ولا يشكل بمفرده نظام إنذار مبكر مضمونًا للزلازل.
