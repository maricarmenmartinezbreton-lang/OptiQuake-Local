# OptiQuake Local — Português

**Criador:** Lic. Juan Esteban Ramírez — República Dominicana.

OptiQuake Local é uma plataforma experimental de código aberto que usa webcams compatíveis como sensores ópticos auxiliares de vibração.

## Instalação
`python -m pip install optiquake-local`

## Integrações
- Skill para sistemas de IA.
- Plugin API v1 para extensões da comunidade.
- Fluxo JSONL para automação.
- Arquitetura preparada para correlação multissensor.

## Limites científicos
A versão atual demonstra observabilidade local de vibrações. Não é um sismômetro certificado, não prevê terremotos, não estima magnitude e, isoladamente, não constitui um sistema garantido de alerta precoce.
