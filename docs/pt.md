# OptiQuake Local — Português
**Criador:** Lic. Juan Esteban Ramírez — República Dominicana.

OptiQuake Local é uma plataforma experimental de código aberto que utiliza webcams compatíveis como sensores ópticos auxiliares de vibração.

## Instalação
`python -m pip install optiquake-local`

## Integrações
- Interface de skill para sistemas de IA.
- Plugin API v1 para extensões da comunidade.
- Fluxo de eventos JSONL para automação.
- Arquitetura preparada para correlação multissensor.

## Limites científicos
A versão atual demonstra observabilidade local de vibrações. Não é um sismômetro certificado, não prevê terremotos, não estima magnitude e não constitui, por si só, um sistema garantido de alerta sísmico precoce.
