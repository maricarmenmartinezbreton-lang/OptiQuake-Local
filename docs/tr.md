# OptiQuake Local — Türkçe
**Geliştirici:** Lic. Juan Esteban Ramírez — Dominik Cumhuriyeti.

OptiQuake Local, uyumlu web kameralarını yardımcı optik titreşim sensörleri olarak kullanan açık kaynaklı deneysel bir platformdur.

## Kurulum
`python -m pip install optiquake-local`

## Entegrasyonlar
- Yapay zekâ sistemleri için skill arayüzü.
- Topluluk eklentileri için Plugin API v1.
- Otomasyon için JSONL olay akışı.
- Çoklu sensör korelasyonuna hazır mimari.

## Bilimsel sınırlar
Mevcut sürüm yerel titreşimlerin gözlemlenebilirliğini gösterir. Sertifikalı bir sismometre değildir; deprem tahmini veya büyüklük tahmini yapmaz ve tek başına garantili bir deprem erken uyarı sistemi değildir.
