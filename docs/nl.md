# OptiQuake Local — Nederlands
**Maker:** Lic. Juan Esteban Ramírez — Dominicaanse Republiek.

OptiQuake Local is een experimenteel open-sourceplatform dat compatibele webcams gebruikt als aanvullende optische trillingssensoren.

## Installatie
`python -m pip install optiquake-local`

## Integraties
- Skill-interface voor AI-systemen.
- Plugin API v1 voor community-uitbreidingen.
- JSONL-gebeurtenisstroom voor automatisering.
- Architectuur voorbereid op multisensorcorrelatie.

## Wetenschappelijke grenzen
De huidige versie toont aan dat lokale trillingen optisch waarneembaar zijn. Het is geen gecertificeerde seismometer, voorspelt geen aardbevingen, schat geen magnitude en vormt op zichzelf geen gegarandeerd vroegwaarschuwingssysteem voor aardbevingen.
