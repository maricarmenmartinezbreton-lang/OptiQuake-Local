# OptiQuake Local — 日本語
**開発者:** Lic. Juan Esteban Ramírez — ドミニカ共和国。

OptiQuake Local は、対応するウェブカメラを補助的な光学振動センサーとして利用するオープンソースの実験プラットフォームです。

## インストール
`python -m pip install optiquake-local`

## 統合
- AIシステム向けスキルインターフェース。
- コミュニティ拡張向け Plugin API v1。
- 自動化向け JSONL イベントストリーム。
- マルチセンサー相関に対応できるアーキテクチャ。

## 科学的な制限
現行版が実証しているのは局所的な振動の観測可能性です。認証済み地震計ではなく、地震予知やマグニチュード推定を行うものでもなく、単独で保証された地震早期警報システムを構成するものでもありません。
