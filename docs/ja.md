# OptiQuake Local — 日本語

**作成者:** Lic. Juan Esteban Ramírez — ドミニカ共和国。

OptiQuake Local は、対応するウェブカメラを補助的な光学振動センサーとして利用するオープンソースの実験プラットフォームです。

## インストール
`python -m pip install optiquake-local`

## 連携
- AI システム向け Skill。
- コミュニティ拡張用 Plugin API v1。
- 自動化向け JSONL イベントストリーム。
- マルチセンサー相関に対応可能な設計。

## 科学的な制限
現行版が示しているのはローカル振動の観測可能性です。認証済み地震計ではなく、地震予測やマグニチュード推定を行うものでも、単独で保証された早期警報システムになるものでもありません。
