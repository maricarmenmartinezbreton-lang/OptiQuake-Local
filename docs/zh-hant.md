# OptiQuake Local — 繁體中文
**建立者：** Lic. Juan Esteban Ramírez — 多明尼加共和國。

OptiQuake Local 是一個開源實驗平台，使用相容的網路攝影機作為輔助光學振動感測器。

## 安裝
`python -m pip install optiquake-local`

## 整合
- 面向 AI 系統的 Skill 介面。
- 面向社群擴充的 Plugin API v1。
- 用於自動化的 JSONL 事件串流。
- 為多感測器關聯分析準備的架構。

## 科學限制
目前版本證明的是本地振動的可觀測性。它不是經過認證的地震儀，不能預測地震或估算規模，也不能單獨作為有保證的地震預警系統。
