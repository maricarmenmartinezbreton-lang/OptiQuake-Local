# OptiQuake Local — ไทย
**ผู้พัฒนา:** Lic. Juan Esteban Ramírez — สาธารณรัฐโดมินิกัน

OptiQuake Local เป็นแพลตฟอร์มทดลองโอเพนซอร์สที่ใช้เว็บแคมที่รองรับเป็นเซ็นเซอร์เชิงแสงเสริมสำหรับตรวจสังเกตการสั่นสะเทือน

## การติดตั้ง
`python -m pip install optiquake-local`

## การเชื่อมต่อ
- อินเทอร์เฟซ skill สำหรับระบบ AI
- Plugin API v1 สำหรับส่วนขยายจากชุมชน
- สตรีมเหตุการณ์ JSONL สำหรับระบบอัตโนมัติ
- สถาปัตยกรรมที่เตรียมไว้สำหรับการเทียบข้อมูลจากหลายเซ็นเซอร์

## ข้อจำกัดทางวิทยาศาสตร์
รุ่นปัจจุบันแสดงให้เห็นว่าสามารถสังเกตการสั่นสะเทือนในพื้นที่ได้ ไม่ใช่เครื่องวัดแผ่นดินไหวที่ผ่านการรับรอง ไม่ได้พยากรณ์แผ่นดินไหว ไม่ได้ประมาณขนาดแผ่นดินไหว และไม่ใช่ระบบเตือนภัยแผ่นดินไหวล่วงหน้าที่รับประกันได้ด้วยตัวเอง
