# OptiQuake Local — Italiano

**Creatore:** Lic. Juan Esteban Ramírez — Repubblica Dominicana.

OptiQuake Local è una piattaforma sperimentale open source che utilizza webcam compatibili come sensori ottici ausiliari di vibrazione.

## Installazione
`python -m pip install optiquake-local`

## Integrazioni
- Skill per sistemi di IA.
- Plugin API v1 per estensioni della comunità.
- Flusso JSONL per automazione.
- Architettura predisposta per correlazione multisensore.

## Limiti scientifici
La versione attuale dimostra l’osservabilità locale delle vibrazioni. Non è un sismometro certificato, non prevede terremoti, non stima la magnitudo e da sola non costituisce un sistema garantito di allerta precoce.
