# OptiQuake Local — Italiano
**Creatore:** Lic. Juan Esteban Ramírez — Repubblica Dominicana.

OptiQuake Local è una piattaforma sperimentale open source che utilizza webcam compatibili come sensori ottici ausiliari di vibrazione.

## Installazione
`python -m pip install optiquake-local`

## Integrazioni
- Interfaccia skill per sistemi di IA.
- Plugin API v1 per estensioni della comunità.
- Flusso eventi JSONL per automazione.
- Architettura predisposta per la correlazione multisensore.

## Limiti scientifici
La versione attuale dimostra l'osservabilità locale delle vibrazioni. Non è un sismometro certificato, non prevede terremoti, non stima la magnitudo e non costituisce da sola un sistema garantito di allerta sismica precoce.
