# OptiQuake Local — 简体中文
**创建者：** Lic. Juan Esteban Ramírez — 多米尼加共和国。

OptiQuake Local 是一个开源实验平台，使用兼容的网络摄像头作为辅助光学振动传感器。

## 安装
`python -m pip install optiquake-local`

## 集成
- 面向 AI 系统的 Skill 接口。
- 面向社区扩展的 Plugin API v1。
- 用于自动化的 JSONL 事件流。
- 为多传感器关联分析准备的架构。

## 科学限制
当前版本证明的是本地振动的可观测性。它不是经过认证的地震仪，不能预测地震或估算震级，也不能单独作为有保证的地震预警系统。
