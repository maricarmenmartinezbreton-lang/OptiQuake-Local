# Contributing to OptiQuake Local

OptiQuake Local is an open-source experimental project created by **Lic. Juan Esteban Ramírez**.

Contributions are welcome from developers, researchers, makers, universities, emergency-technology communities, and AI-agent projects.

## Ways to contribute

- Improve vibration-detection algorithms and calibration.
- Add support for more cameras, microphones, IMUs, or dedicated MEMS sensors.
- Add Linux/macOS capture backends in addition to Windows DirectShow.
- Build adapters for OpenClaw/JARVIS, MCP, n8n, Home Assistant, or other agent systems.
- Add reproducible tests, datasets, documentation, translations, and accessibility improvements.
- Research false-positive rejection and multi-sensor correlation.

## Contribution workflow

1. Fork the repository and create a focused branch.
2. Keep changes modular and independent of private infrastructure.
3. Add or update tests for behavior you change.
4. Document hardware, sampling rate, placement, and test conditions for sensor claims.
5. Open a pull request explaining what changed, how it was tested, and known limitations.
6. Do not describe a feature as earthquake detection or early warning unless evidence supports that claim.
